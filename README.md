# Thiadiaye Debout

Plateforme citoyenne du mouvement Thiadiaye Debout. Trois projets indépendants :

- [`backend/`](backend/) — API Laravel
- [`admin/`](admin/) — Back-office React (équipe du mouvement)
- [`web/`](web/) — Site public citoyen React

Chaque dossier a son propre `README.md` avec les instructions d'installation.

Voir [`SUIVI_PROJET.md`](SUIVI_PROJET.md) pour l'état d'avancement détaillé du projet.
